# Azure architecture icons

The SVG files in this folder are selected from Microsoft's Azure Public Service
Icons package. They are bundled locally so opening an architecture diagram does
not make network requests.

Microsoft permits use of these icons in architecture diagrams, training
materials, and documentation. Keep the service name close to the icon and do
not distort, crop, flip, or rotate it. Source and terms:
https://learn.microsoft.com/azure/architecture/icons/

The sibling `../brands/` folder contains runtime and platform logos from
Simple Icons (CC0-1.0). Brand names and logos can still be subject to their
owners' trademark guidelines: https://github.com/simple-icons/simple-icons/
